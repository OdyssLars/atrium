# ATRIUM — Hotel Reservation System

Final Exam project for Development of Web Applications in Java Spring.
Github was made in advance so we would be able to complete it in future.

Guests explore a three-floor hotel, select a room, check availability
and complete a reservation.

## Technologies
Java Spring Boot, React, Three.js, PostgreSQL, Spring Data JPA, Maven.
